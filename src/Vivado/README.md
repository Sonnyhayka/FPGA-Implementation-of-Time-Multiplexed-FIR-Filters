# Time-Multiplexed Fixed-Point FIR (Vivado RTL)

Parametric `N`-tap FIR using `M` time-multiplexed MAC units. Computes one output every `N/M` cycles by reusing the MACs, with a selectable delay-line implementation.

## Files
| File | Module | Role |
|---|---|---|
| `fixed_point_mac.v` | `fixed_point_mac` | One signed multiplier plus clearable accumulator |
| `coeff_bram.v` | `coeff_bram` | Coefficient memory, serves `M` coeffs per cycle from a packed BRAM word |
| `fir_delay_line.v` | `fir_delay_line` | Sample delay line, regular registers (`SRL_REG=0`) or SRL16 (`SRL_REG=1`) |
| `fir_time_mux_controller.v` | `fir_time_mux_controller` | Cycle counter, address and MAC control, valid generation |
| `fir_time_mux_top.v` | `fir_time_mux_top` | Top level, instantiates everything plus the adder tree and output conversion |
| `tb_fir.v` | `tb_fir` | Testbench, instantiates `SRL_REG=0` and `SRL_REG=1` and writes both outputs |

## Parameters
Set on `fir_time_mux_top`:
- `N` taps (default 64), `M` MAC units (default 4), requires `N % M == 0`
- `SRL_REG` delay-line mode (0 regular registers, 1 SRL16)
- `IN_WIDTH=12`, `COEFF_WIDTH=16`, `OUT_WIDTH=12`
- `IN_FRAC=10`, `COEFF_FRAC=15`, `OUT_FRAC=10`
- `COEFF_FILE` coefficient memory init file

Derived internally: `ACC_WIDTH = IN_WIDTH + COEFF_WIDTH + clog2(N)` (34 bits for N=64), product Q3.25, accumulator Q3.25, output conversion shifts by `PROD_FRAC - OUT_FRAC` with round half away from zero and saturation to the output range.

## Fixed-point mapping
Blocked tap assignment: MAC `m` handles taps `16m .. 16m+15`. At cycle `c`, MAC `m` reads coefficient `h[16m+c]` and sample `x[n-(16m+c)]`. The four partial sums are combined by the adder tree, then converted to the output format. This matches `src/matlab/fir_golden_model.m` bit for bit.

## Data files
Generated by the MATLAB golden model into `data/`:
- `x_q210.txt` input samples, 12 bit two's complement binary, one per line (`$readmemb`)
- `h_q115.txt` coefficients, 16 bit two's complement binary, one per line (`$readmemb`)

Place these (and the produced outputs) in the simulator working directory, or pass absolute paths through `INPUT_FILE` / `COEFF_FILE`.

## Simulate
```
iverilog -g2012 -o sim tb_fir.v fixed_point_mac.v coeff_bram.v fir_delay_line.v fir_time_mux_controller.v fir_time_mux_top.v
vvp sim
```
Produces `fir_output_srl0.txt` and `fir_output_srl1.txt`, one signed Q2.10 integer per line. Verified bit exact against `data/y_matlab_q210.txt` for all 4000 samples, with `SRL_REG=0` and `SRL_REG=1` identical.

## Synthesize
Set `fir_time_mux_top` as the synthesis top. Run once with `SRL_REG=0` and once with `SRL_REG=1` (same `N=64`, `M=4`) and capture each utilization report. Expect `SRL_REG=1` to move the delay line out of flip-flops into SLICEM LUTs (SRL16/SRLC).

## Interface and timing
Handshake: assert `in_valid` with `x_in`; the core accepts when `in_ready` is high. `out_valid` pulses for one cycle with `y_out`. Output `i` corresponds to input `i` (causal, zero initial state), so no reordering is needed; only the pipeline latency offsets when each `out_valid` appears.
